# P6 Deployment (planned)

**Requirement (PDF, P6):** a way to run the software outside the development environment. Cloud is not needed: Dockerfile plus compose file, start script plus config, or a local web server. Artifacts must be generated by the environment, consistent with the design, and they must work.

**Suggested design**

- Agent: `deployer`. Input: component/deployment diagram and the code layout.
- New port `Sandbox` with adapters for `docker build` / `docker run` and a plain subprocess start; a smoke check (process starts, HTTP 200 or CLI exit code 0) decides success, not the LLM.
- Consistency check: every component in the deployment diagram has a service or start command.

**Grading hooks:** C1, C7 ("the deployment runs").
